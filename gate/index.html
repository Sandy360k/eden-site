Built-in Remote Desktop

Windows PCs, right in a tab.

No separate Remote Desktop window to juggle. Eden Gate draws the remote screen itself.

  • Fits the window. The remote desktop follows the tab's size, or full screen with one key.
  • Tear it off. Drag a session into its own window and back; it keeps running.
  • Through a jump host. Reach a PC behind an SSH server without opening a port.
  • Your own client as a fallback. One click opens the same PC in Windows App on a Mac, or Remote Desktop on Windows.

Security

Built to be trusted with the keys.

A session manager holds the keys to everything you run. Eden Gate is built so a stolen server, a spoofed machine or a compromised remote PC gets as little as possible.

  • End-to-end encrypted vault. Passwords and keys are sealed on your device (XChaCha20-Poly1305, Argon2id) before they sync. Our servers store only what they can't read.
  • Unlock with a passkey. Touch ID or Windows Hello, with a passphrase and a recovery key you keep as the way back in.
  • No surprise machines. SSH host keys and Remote Desktop certificates are pinned on first contact; a change is refused, and no password is sent first.
  • Safer sign-in by default. Remote Desktop uses NLA unless you allow otherwise for a machine you trust.
  • Sealed shared folders. Every path a remote PC asks for is checked against your folder, symlinks included; read-only refuses every change.
  • Hard boundaries. Mark a machine as on a restricted network and nothing crosses it: no clipboard, no shared folder, no tunnels.
